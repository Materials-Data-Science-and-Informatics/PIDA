
## Artifact name
 ConnOSS metadata schema

### Overview

Connected Open-Source Software (ConnOSS) is a DFG funded project. The ConnOSS vocabulary is a metadata schema extending CodeMeta and Schema.org and aiming at describe research software as a research artifact, aligned to needs from the German community, e.g., NFDI and deRSE.
